# ✈️ HopNTrip

**🔗 Live Website:** [https://hopntrip-top-sabah-agency-website.netlify.app](https://hopntrip-top-sabah-agency-website.netlify.app)

HopNTrip is a modern, responsive travel agency and booking web application dedicated to showcasing and facilitating travel adventures to **Sabah, Malaysia (Borneo)**. The platform provides comprehensive guides and booking interfaces for hotels, flight booking, tour packages, travel insurance, and customizable itineraries to iconic destinations such as Mount Kinabalu, Kundasang, Sepilok Orangutan Rehabilitation Centre, and Sipadan Island.

---

## 🌟 Key Features

- **Interactive Booking Portals**: Highly responsive pages for searching and scheduling flight bookings and hotel stays.
- **Tailored Tour Packages**: Detailed showcases of Sabah's top travel itineraries (eco-tourism, cultural highlights, wildlife safaris, and beach retreats).
- **Travel Insurance Portal**: A complete interface to explore and secure comprehensive travel coverage.
- **Immersive Destination Showcases**: High-resolution image galleries and dynamic video highlights of Borneo's natural attractions.
- **Secure Authentication Flow**: Integrated login and registration forms for travelers.
- **Credential & Trust Showcases**: Showcases HopNTrip's professional accolades, such as IATA certification and Eco-Tourism awards.

---

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (custom responsive grid layouts, animations, transitions, and styled controls).
- **Multimedia**: Optimized high-definition travel photography, custom iconography, and high-performance MP4 video previews.

## 🚀 How to Run Locally

Since this is a client-side static web application:

1. **Clone the Repository** (once created on GitHub):
   ```bash
   git clone https://github.com/Jade-0703/HopNTrip.git
   ```
2. **Open the Application**:
   - Double-click [index.html](file:///Users/jadewenxi/Documents/WEB%20SEM3/Assignment/test%20all/index.html) to view the site directly in any modern browser.
   - Alternatively, serve it using local server extensions such as **Live Server** in VS Code for live reload support.
